This audit covers only cdHash `64a09464023aa47514a78be456da5b89e01b50a6`,
the locally modified image displaying 2.1.257 and tweakcc 4.3.3. It establishes
settings-loader compatibility. **It does not grant custom-build trust.** The

## Provenance and complete binary comparison

The local 205,871,808-byte arm64 image passes complete strict code-signature
validation, but is ad-hoc signed, identifier `2.1.257`, without a team. It fails
the explicit Anthropic requirement. Neither its filename nor its displayed
version proves an official distribution or authorizes delegation.

The reference is Anthropic's [official 2.1.257 arm64 archive](https://github.com/anthropics/claude-code/releases/download/v2.1.257/claude-darwin-arm64.tar.gz),
whose SHA-256 matches the [published release asset digest](https://github.com/anthropics/claude-code/releases/expanded_assets/v2.1.257):
`4ca35800ac8cf42e9c134b6bb9253edd65174379f46050c915af119fe15d8534`.
Its single 199,011,264-byte member passes complete strict signature validation
and the explicit Anthropic identifier/team requirement (`Q6L2SF6YDW`, hardened
runtime, signed 1 September 2026). Neither image was executed.

The local native payload, from the end of Mach-O load commands at byte 2,816
to the Bun graph length at 66,338,816, is byte-identical to the official
image. The original graph data before the module table is also unchanged.
The graph base is 66,338,824; the module table starts at 198,304,714 and has
1,818 records of 52 bytes. All original compiled module ranges and all
unchanged content ranges match. Eight records point to appended replacement
source. Load/signing metadata, graph length and those source pointers account
for the surrounding relocation; this is not a replacement native runtime.

The table selects 1,640 UTF-8 source modules: 32,498,004 bytes in the official
image and 32,503,282 in the custom image. A marker scan alone sees 1,648
chunks in the custom image because the eight replaced originals remain in
the binary. A tail-only filename scan therefore cannot map this image.
Both table-derived source maps pass all 42,981 static internal import/export
checks. Original bytecode ranges remain present, so both original and
replacement source were inspected; a source edit alone is not evidence that
cached bytecode executes it.

## Probes and regression coverage

Ten offline probes execute selected extracted functions or AST expressions
with synthetic dependencies: G1 layer selection; all-source shell allows;
alias precedence; both v5 flag states; generated-policy payload normalization;
classifier body overrides; main/REPL ordering; rename cycles/removals/depth;
root-skill fallback; and the custom memory switch. They import no upstream
module, run neither executable and read no real configuration or credential.
They establish selected local behavior, not server behavior or arbitrary
plugin/helper safety. Reproduction tools and value-free output are attached
to the work bead; upstream executable/source is not committed or attached.

Synthetic csec regressions bind the catalog to this exact hash and keep
neighboring hashes unchecked. They exercise this ad-hoc identity on all three
delegation paths with and without independent custom-build trust. Only the
trusted case may delegate; the untrusted case retains ordinary review.
Suite/build, commit/push/install and installed-daemon acceptance evidence
remain on the work bead.
