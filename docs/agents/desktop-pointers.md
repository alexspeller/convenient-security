## Desktop pointers

When a coding-agent command needs to point at a native approval, follow
[`docs/desktop-pointing.md`](docs/desktop-pointing.md). An empty big-arrow
display list can come from Codex's command sandbox even in the Aqua session;
use the normal per-command escalation route and permission-free targeting
before considering a new privacy grant. Big-arrow's responsible-app label is
a parent-process guess; verify TCC attribution before proposing a grant. Its
0.4.3 window matcher and app binding also exclude csec's modal panels; use the
guide's verified-coordinate route for those panels.
