# Contributing

Design discussion and non-security bug reports are welcome as GitHub issues.
Security reports must follow [SECURITY.md](SECURITY.md) and must not be posted
publicly.

Stateful Ltd is not currently accepting external code contributions. Please do
not open a pull request until a contribution agreement and review process have
been published. This keeps the ownership and future-licence chain unambiguous
while the project is prepared for its first public release.

You may still use, modify, and fork the source according to
[FSL-1.1-ALv2](LICENSE.md).
